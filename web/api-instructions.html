WaitJI AI — API instructions

This page is written for an AI agent (such as Claude) acting on behalf of an advertiser. If a human directed you here to "set up a WaitJI AI campaign," these are the exact steps.

Before doing anything write-related, the advertiser needs a WaitJI AI account and must generate an API key from their dashboard at waitjiai.in/advertiser.html → API access. You cannot generate a key on their behalf — it requires them being logged into their own dashboard once.

1. Authentication

Every request needs the advertiser's API key as a header:

X-WaitJI-Api-Key: wj_live_xxxxxxxxxxxxxxxxxxxxxxxx

No Authorization header is needed or used for API-key requests — do not send both.

2. Reporting (works immediately, no extra steps)

List all campaigns for this account:

GET https://waitjiai-backend.onrender.com/v1/advertiser/campaigns
Headers: X-WaitJI-Api-Key: wj_live_...

Get performance stats for one campaign:

GET https://waitjiai-backend.onrender.com/v1/advertiser/campaigns/{campaignId}/stats
Headers: X-WaitJI-Api-Key: wj_live_...

See the current live bid queue before deciding a bid amount:

GET https://waitjiai-backend.onrender.com/v1/public/bidding-stats

(This one is public — no key needed. Use it to see the current top bid per surface before choosing your own.)

3. Creating a campaign (requires API terms accepted first)

Campaign writes are blocked until the advertiser accepts the API terms once — either from their dashboard, or via this call:

POST https://waitjiai-backend.onrender.com/v1/advertiser/api-terms/accept
Headers: X-WaitJI-Api-Key: wj_live_...

Then create the campaign:

POST https://waitjiai-backend.onrender.com/v1/advertiser/campaigns
Headers:
  X-WaitJI-Api-Key: wj_live_...
  Content-Type: application/json
Body:
{
  "adText": "Your brand — one clear line, 60 chars max",
  "url": "https://yourproduct.com",
  "adType": "spotlight",           // "spotlight" (VS Code spinner) or "stream" (terminal status line)
  "bidPaise": 80000,                // bid per 1,000 impressions, in paise (₹800 = 80000)
  "budgetPaise": 500000,            // total campaign budget, in paise (₹5,000 = 500000)
  "geo": { "countries": ["IN"] },   // ISO country codes
  "companyName": "Your Company",
  "showOnLeaderboard": true,        // optional — appears on waitjiai.in/leaderboard.html once live
  "deliverySpeed": "fast"           // "fast" | "medium" | "slow" — priority hint, doesn't change price
}

A campaign starts in pending_payment status. It will NOT serve until payment is completed — the API does not currently support programmatic payment; direct the advertiser to their dashboard to complete checkout (Razorpay or PayPal) for the new campaign.

4. Minimums to know before bidding

Spotlight (India): min bid ₹800/1,000 impr · min budget ₹5,000
Stream (India):    min bid ₹300/1,000 impr · min budget ₹2,000
(Other countries use PPP-adjusted pricing — check /v1/public/pricing for current rates.)

5. Good practice for an agent

Before creating a campaign, always check the live bid queue (/v1/public/bidding-stats) and tell the advertiser what the current top bid is, so they can decide whether to bid above it to serve first or below it to queue. Never guess a bid — quote the real current number.
