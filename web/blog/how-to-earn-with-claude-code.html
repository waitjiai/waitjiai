Every developer using Claude Code spends time waiting. Between 3 and 15 seconds per prompt, depending on the task. Over a typical 4-hour coding session, that's 20–40 minutes of idle time — time where your screen is showing the animated Thinking... spinner and you're doing nothing except waiting.

WaitJI AI converts those pauses into UPI income. Here's exactly how it works, what you can realistically earn, and how to set it up in under 5 minutes.

What actually happens under the hood

Claude Code has an officially documented configuration setting called spinnerVerbs in ~/.claude/settings.json. This setting controls what text appears in the animated thinking spinner. By default it cycles through words like "Thinking", "Pondering", "Analyzing".

WaitJI AI updates this setting — with your permission — to include sponsored text from advertisers. So instead of seeing ⠋ Thinking…, you see something like ⠋ WaitJI: Scaler — India's top bootcamp · Apply. The spinner still spins. Claude Code still works exactly the same. The only difference is one line of text in a spinner you were already watching.

WaitJI AI never reads your code, prompts, or Claude Code's responses. It only writes to the spinnerVerbs config field.

Advertisers pay per 1,000 impressions (CPM). You keep 65% of every impression. The rest covers platform costs, fraud protection, and developer operations.

Setting it up: 4 steps

1

Open Terminal and run the install command. This downloads and installs the WaitJI AI extension into VS Code.

curl -L https://waitjiai.in/vsix -o waitji.vsix && code --install-extension waitji.vsix
2

Go to waitjiai.in and sign up with your email. No credit card, no subscription. Your account gives you a User ID for the extension to identify your impressions.

3

Connect the extension

In VS Code, press Cmd+Shift+P → type "WaitJI AI: Connect" → paste your User ID from the dashboard. The extension confirms connection and starts the background poller.

From your dashboard, go to Profile → Payment settings → enter your UPI ID (e.g. yourname@okaxis). This is where your earnings get paid. Once you reach ₹100, you can request withdrawal anytime.

Agentic Claude Code tasks — "refactor this entire module", "write tests for all these functions" — generate more impressions because Claude Code thinks more. A 30-minute agentic session can generate the same impressions as 2 hours of short prompts.

Is it safe? Does it affect Claude Code?

WaitJI AI is safe, non-intrusive, and does not affect Claude Code's performance in any way. The extension:

  • Only modifies ~/.claude/settings.json — Claude Code's own config file
  • Never intercepts network requests, file system access, or Claude Code's AI responses
  • Never reads your code, prompts, or conversation history
  • Uses less than 1KB of bandwidth every 90 seconds for the ad polling request
  • Can be disabled or uninstalled at any time from VS Code Extensions panel

Troubleshooting: why isn't my dashboard showing earnings?

A few things account for almost every case of "I installed it but I'm not earning":

  • You haven't connected your account yet. The extension shows ads either way, but only credits earnings once your User ID is linked — check Command Palette → "WaitJI AI: Connect Your Account".
  • Only house ads are showing. When no paid advertiser campaign is active for your region, WaitJI AI shows its own promotional messages instead — these don't earn you anything, but the extension is still working correctly and will start crediting real impressions the moment a paid campaign matches.
  • Your activity looks automated to the fraud system. Impressions and clicks that come in faster than a human plausibly could (see the fraud protection thresholds in our FAQ) aren't billed to advertisers or credited to you — this only affects genuinely abnormal patterns, not normal heavy use.
  • VS Code isn't actually running. The poller that fetches ads and records impressions is a background process tied to VS Code being open — it can't earn on your behalf while VS Code is fully closed.

Frequently asked questions

Does WaitJI AI work on Mac, Windows, and Linux?

Yes. The extension works on all platforms where VS Code and Claude Code are supported — macOS (Intel and Apple Silicon), Windows 10/11, and Ubuntu/Debian/Arch Linux.

What if there are no advertisers running campaigns?

WaitJI AI shows house ads (WaitJI AI's own promotions) when no paid campaigns are active. You don't earn on house ad impressions, but the extension always shows something. As the advertiser base grows, paid impression density increases.

When does my ₹100 minimum reset?

There is no reset — your balance accumulates indefinitely until you request a withdrawal. You can withdraw any amount above ₹100 at any time. Unused balance never expires.
