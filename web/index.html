Foreign spinner-ad apps se kya farak hai? ▼
Sabse bada farak: woh Indian developers ko pay hi nahi kar sakte. Unka payout system (Stripe) India mein paise nahi bhejta — aapka earning account mein dikhता hai but withdraw nahi hota. 3 ads per wait — yeh annoying nahi hoga? ▼
Nahi. Ads sirf status bar mein 1-line text hote hain, aur rotate karte hain wait duration ke according. Agar wait 3 second hai toh 1 ad, agar 15 second hai toh 3 ads. Developer ka flow break nahi hota — yeh non-intrusive design hai.
Referral se paisa kab tak milega? ▼
Lifetime. Jab tak woh developer WaitJI AI use karta hai, aapko unke impressions ka 10% milta rahega. Yeh passive income hai — ek baar invite karo, lambe time tak earning. Isiliye early adopters ko zyada fayda hota hai.
Kya yeh legal hai? Claude terms violate hote hain? ▼
Bilkul legal. WaitJI AI ek VS Code extension hai jo status bar mein text dikhata hai — VS Code Extension API ka standard documented use. Claude Code ke koi terms violate nahi hote. Hum Anthropic ke saath koi partnership claim nahi karte. Extension sirf aapki local machine pe chalta hai.

Minimum ₹100. Request ke baad 2-3 business days mein UPI pe. Razorpay Payouts use karte hain. Koi hidden charges nahi.
