// FAQ
Sawaal jo aate hain.
Kya yeh legal hai? Kya Claude ke terms violate hote hain? ▼
Haan, bilkul legal hai. WaitJiai ek VS Code extension hai jo status bar mein text dikhata hai — yeh VS Code Extension API ka standard, documented use hai. Claude Code ke kisi bhi terms violate nahi hote. Hum Anthropic ke saath koi partnership claim nahi karte. Extension sirf aapki local machine pe kaam karta hai.
Extension install karne ke baad kya karna hoga? ▼
Sirf apna UPI ID settings mein daalo (VS Code → Settings → WaitJiai → UPI ID). Phir kuch nahi — bas Claude Code use karte raho jaise pehle. Extension automatically impressions track karega aur earnings accumulate hongi. Month end pe withdraw karo.
Minimum withdrawal kitna hai? Kitne time mein milega? ▼
Minimum withdrawal ₹100 hai. Request karne ke baad 2-3 business days mein UPI pe aa jaata hai. Hum Razorpay Payouts use karte hain — India ka most trusted payout system.
₹25,000/month realistic hai? ▼
Heavy Claude users ke liye — jaise koi full-time developer jo din mein 50+ sessions use karta hai — ₹1,500 to ₹3,000/month akele apni machine se possible hai. ₹25,000 target ke liye referral system important hai — aap dusre developers ko invite karo aur unke impressions ka bhi % aapko milega. Exact numbers calculator mein dekho upar.
Advertisers ke liye minimum ₹200 CPM kyun? ▼
Isse do cheezein ensure hoti hain: (1) Developers ko meaningful earnings milti hain — ₹100 CPM pe toh ₹25k target bahut mushkil hota. (2) Platform pe sirf serious brands aate hain jo genuinely developer audience ko value karte hain. Quality over quantity.
Advertiser ke taur pe kaise measure karein? ▼
Advertiser dashboard mein real-time impressions, clicks, CTR, aur spend dikhega. Campaign live hone ke baad hourly updates. CPM aur CPC dono track hote hain. UTM parameters support karta hai — apne analytics ke saath integrate karo.
Kya meri personal data collect hoti hai? ▼
Sirf ek anonymous device ID generate hoti hai — koi naam, email, ya personal info nahi. UPI ID sirf withdrawal ke waqt store hota hai, encrypted. Koi third party ke saath data share nahi hota. Full privacy policy → waitjiai.in/privacy
